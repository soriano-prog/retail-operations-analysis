## Retail Risk & Operational Optimization Analytics

### Project Overview
This project analyzes retail operational data to identify the key factors influencing business risk using Microsoft Excel and IBM SPSS Statistics. A dataset containing 15,000 retail observations was examined to evaluate pricing, inventory, customer behavior, and operational performance through dashboard reporting and statistical analysis. The project demonstrates how descriptive and inferential analytics can support data-driven decision-making in retail operations.

### Tools
- Microsoft Excel was used to develop an interactive dashboard, calculate key performance indicators (KPIs), create PivotTables, and visualize operational trends through charts and business reports.
- IBM SPSS Statistics was utilized to perform descriptive statistics, assess data assumptions, conduct correlation analysis, build a multiple linear regression model, compare group differences using One-Way ANOVA, and examine associations between categorical variables using the Chi-Square Test of Independence.

### Findings
The analysis revealed that customer sentiment and return rate were the strongest factors influencing retail risk. The multiple linear regression model explained 43.4% of the variation in retail risk score, indicating moderate predictive capability. Furthermore, retail risk differed significantly across stock categories, while the relationship between stock status and risk category was statistically significant but exhibited a very weak association. Overall, the findings suggest that customer experience and inventory management play important roles in reducing operational risk.

### Conclusion
The project demonstrates how Microsoft Excel and IBM SPSS Statistics can be integrated to transform retail data into actionable business insights. Through dashboard development and statistical modeling, the analysis identified key operational factors associated with retail risk and provided evidence-based insights that can support inventory management, pricing strategies, and customer-focused decision-making.
