### Data
This folder contains the dataset used for this project. The data was obtained from **Kaggle** and includes **15,000 retail observations**. The dataset was pre-cleaned, and additional variables were created to support dashboard development and statistical analysis.

**Source:** retail store product sales dataset (Kaggle)

https://www.kaggle.com/datasets/ranaghulamnabi/retail-store-product-sales-dataset-analysis
